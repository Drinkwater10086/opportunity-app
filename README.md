## 直接在线使用

普通使用者只需要浏览器，不需要安装Python、启动服务或填写DeepSeek/智谱密钥。

1. 打开上方网站入口，点击 **新建采集批次**。
2. 填写需求方向及检索词，选择来源、条数上限和时间窗口，点击 **采集公开数据**。
3. 采集完成后，点击当前批次的 **进入程序分析**。
4. 保留默认参数，点击 **开始程序分析**，查看分析结论、候选机会、主题及原文证据。
5. 有主题时整理策划并保存修订；导出四份CSV、实验JSON和策划Markdown。

每次新采集建立一个独立批次；同一批次可保存多次独立实验用于对照。没有记录满足条件时会输出空结果，不强行编造机会。每个环节保留批次、记录及原文追溯信息。

## 当前网站如何运行

GitHub Pages发布固定入口，代码和文档通过Git管理；**Python后端与数据库仍运行在项目主机**，由HTTPS测试隧道供队友访问。项目主机和隧道需保持运行。临时地址变化后，维护者更新入口并推送GitHub；访问者刷新固定入口即可。

当前公网演示站可直接使用，访问者共享测试数据。仓库标准版本另有账号权限配置。GitHub账号不是应用账号，请勿输入私密资料。运行数据库、API密钥及采集正文不发布到公开Git仓库。

此外还启用Hacker News、Super User、The Workplace、Node-RED和arXiv。总计 **13个平台、14个采集选项**；GitHub两种选项算同一个平台。n8n、Make因使用条件限制停用。

所有订阅和近期流均受当前返回条目限制，不能靠调大条数覆盖完整历史。论文、数据集目录和产品资料属于技术资源，媒体摘要属于二手报道；并非都能成为用户需求。图片、PDF、音视频尚未自动OCR或转录。

未接入的12个平台：哔哩哔哩、掘金、少数派、CSDN、机器之心、36氪、阿里云开发者社区、Papers with Code、Semantic Scholar、天池、DataFountain、数睿思。具体尝试见[逐项复核记录](SOURCE_ACCESS_REVIEW.md)；哪些可以由团队申请账号、授权或联系平台解决，见[来源接入协作说明](SOURCE_AUTH_GUIDE.md)。采集页也展示全部20个平台的状态、官方依据和后续条件。

## 分析方案与结果限制

规则判别、默认LSA/TF-IDF表示、聚类、评分和评价均在项目主机执行，**不调用外部生成式大模型**。外部大模型分析、Key配置及解锁入口已退役。可选本地E5向量需维护者按说明准备，不自动下载模型。

轮廓系数评价指定向量空间的分组结构，ARI比较同输入聚类一致性，均不是准确率。无人工真值时不报告准确率或F1。程序策划是有证据和待验证假设的初稿，不能代替实际用户访谈。

最近一轮完整回归303项通过；两家新RSS来源的真实批次采集成功，分析与离线重放一致。测试通过不证明机会判断正确。赛事最终论文和完整提交包仍未完成，详见[赛事要求与差距](CONTEST_CHECKLIST.md)。

## 仅供维护者：运行后端

普通在线使用者无需执行本节。需要Python 3.12；以下启动仓库标准账号版，公网演示配置单独维护。运行前确认依赖来自requirements.txt。

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

维护者在本机访问http://127.0.0.1:8000，标准账号版首次需创建管理员。数据库存放于data/，不会提交Git。公网访问须另行启动已有HTTPS通道并更新docs/index.html入口；GitHub Pages本身不能运行此Python后端。

测试命令为`python -m pytest -q`，需先安装requirements-dev.txt中的测试依赖。后台停止、主机休眠或隧道失效时在线站会不可用；恢复后再更新固定入口。
