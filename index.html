GitHub 问题按发布时间筛选，项目简介按最近代码更新筛选，问答站按问题发布时间筛选，Hacker News 按帖子或评论发布时间筛选（外链文章正文不采集）。Super User、The Workplace 与 Stack Overflow 同属 Stack Exchange 网络，共享接口限流。自动分页，遇到限流保留已采集页面并标记未完成；条数为上限，热度指标不跨平台直接相加。Node-RED 官方论坛最多扫描近期10页、补取30条单帖正文，并按关键词筛选后以样本阅读计数排序，不是全站历史搜索。官方社区中的用户陈述未经独立证实。V2EX 只筛选最新接口当前返回的公开主题；arXiv 只筛选当日 cs.AI 订阅摘要，周末可能为空，论文不单独作为真实需求证据。订阅源不支持历史全站搜索。Product Hunt只查产品名称和标语，每组最多8项、最多近365天，不取评论或账户资料。图片、视频、音频和PDF暂不自动转录。
